## (b) Question → query on TD.3

**This is a floor, not T4.2's number.** Output is constrained only to well-formed JSON; T4.2 constrains it to T4.1's schema, which can only make more outputs valid. Every model gets the same prompt and the same 8 worked examples, chosen before any model ran and not scored: q002, q022, q035, q037, q040, q041, q051, q068.
